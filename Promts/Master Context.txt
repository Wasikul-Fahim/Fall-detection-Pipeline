You are acting as a Senior Machine Learning Research Engineer and Software Architect.

I am building a research framework for my Bachelor's thesis on human fall detection using deep learning.

The purpose of the framework is NOT just to train one model.
Its purpose is to allow me to rapidly research and compare different datasets, image representations, neural networks, anomaly detection algorithms, and evaluation methodologies with minimal code modifications.

========================================================
PROJECT OVERVIEW
========================================================

Original Dataset

The original data consists of raw accelerometer and gyroscope sensor signals stored as .txt files.

The images used for training are generated from these sensor signals.

Currently another computer generates these images because my local Mac is not powerful enough.

The generated images are the training inputs.

Examples include

- Spectrogram
- Scalogram
- Kurtogram

These are combined into mosaic images.

Currently the mosaic layout is 2x2, but this may change to any grid size in the future.

Therefore the framework must NEVER assume any fixed image representation.

The original sensor data must always be considered the source of truth.

The framework should automatically index this directory instead of manually copying images into train/validation/test folders.

The indexing process should generate metadata files (CSV or similar).

The dataset should be split by SUBJECT rather than by image to avoid data leakage.

========================================================
PRIMARY RESEARCH OBJECTIVE
========================================================

The immediate objective is to evaluate Vision Transformer (ViT) models for fall detection using mosaic images generated from accelerometer and gyroscope sensor data.

The framework should initially be built around ViT while remaining generic enough that additional models can be integrated later with minimal changes.

Future models include:

- EfficientNet
- ResNet
- ConvNeXt
- Swin Transformer
- PatchCore
- PaDiM

The architecture should avoid becoming tightly coupled to ViT, even though ViT is the first implemented model.

# Research Framework Context (Continuation)

I am building a **modular deep learning research framework** for my thesis on **Human Activity Recognition / Fall Detection**. The framework should be reusable for multiple models (ViT, EfficientNet, ConvNeXt, Swin, PatchCore, PaDiM, etc.) and should follow professional software engineering practices.

Please use this context when answering future questions.

---

# Overall Goal

The framework should:

* Be modular and maintainable.
* Follow SOLID principles where appropriate.
* Keep modules independent.
* Use type hints.
* Use docstrings.
* Avoid duplicated code.
* Keep functions small.
* Be easily extensible.
* Run on:

  * Local MacBook (development)
  * Google Colab
  * Lab PCs with RTX 4080 / RTX 4090 GPUs
* Eventually support datasets ranging from ~15k images to over 500k images.

# Important Design Decision

Initially we built ImageDataset by recursively scanning folders.

Later we realized this is NOT suitable for:

* subject-wise splitting
* reproducibility
* scalability
* fair comparison between models

So we redesigned the Dataset Module.

Current intended architecture:

Dataset Folder

↓

indexer.py

↓

metadata.csv

↓

splitter.py

↓

train.csv
val.csv
test.csv

↓

ImageDataset (reads CSV)

↓

DataLoader

---

# image_dataset.py

Originally:

ImageDataset(root_dir=...)

Now redesigned to:

ImageDataset(csv_file=...)

The dataset should:

* read a CSV
* load image
* apply transforms
* return image + label

It should NOT:

* scan folders
* split dataset
* know anything about ViT

---

# indexer.py

Purpose:

Scan the dataset once.

Generate metadata.csv.

Each row contains:

image_path
label
activity_type
activity
subject

---

# splitter.py

Purpose:

Perform SUBJECT-WISE split.

Generate

train.csv
val.csv
test.csv

No random image split.

No data leakage.

---

# Why random_split() was removed

Initially train_vit.py used:

train_dataset, val_dataset = random_split(...)

This is NOT acceptable for thesis experiments because images from the same subject can appear in both training and validation.

Since my goal is to evaluate ViT for the thesis (not just test the pipeline), we decided to remove random_split() entirely.

---

# Current train_vit.py

Instead of

dataset = ImageDataset(root_dir=...)

random_split(...)

it should create

train_dataset = ImageDataset(csv_file="metadata/train.csv")

val_dataset = ImageDataset(csv_file="metadata/val.csv")
